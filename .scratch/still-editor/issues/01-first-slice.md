# First still-scene editor
Category: enhancement
Status: ready-for-human

## Agent Brief

Current behavior: repository contains design documentation only. Searches of tracked source and local issues found no existing editor or prior rejection.

Desired behavior: Ruby app logic on JRuby 10.1.x/JDK 25 with a Swing editor on Apple Silicon macOS. Users create cubes, spheres, planes, and point lights; select through tree or viewport; create named one-level groups; edit inherited transforms numerically and translate through draggable RGB world-axis arrows. Solid CPU preview uses the single camera's framing. Materials expose RGB and 0–100 reflection, specular, roughness. Point lights expose position, RGB, brightness. Scenes save/reopen using XML validated by an enforced XSD on read and written bytes before replacement. CPU still rendering supports hard shadows, mirror/rough reflection, progress/cancel, PNG/BMP/JPG, default PNG/1920×1080, and custom positive dimensions subject to memory safety.
